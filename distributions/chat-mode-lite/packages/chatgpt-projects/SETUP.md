# Project setup / 项目设置

## English

1. Confirm your account/workspace offers Projects and editable project instructions. See HOST_REQUIREMENTS.md; these steps prepare manual configuration and have not been performed in an account.
2. Create or choose the intended private project. In its project instruction setting, paste **all** of PROJECT_INSTRUCTIONS.md and save. UI labels may differ. Read it back to confirm the ending and version survived; uploading it as a source is not a substitute.
3. Add REFERENCE_PACK.md as one project source using the available file/source control. Keep the exact filename. UPLOAD_MAP.md specifies the content; do not upload this guide, Preview plans, design documents, example answers or user checkpoints as reusable knowledge. If upload format/size is rejected, use portable paste setup rather than removing mandatory content.
4. Start a conversation inside that project. Ask which package version and selected procedure are actually accessible. For a task, ask it to consult the named workflow and companions. If access is partial/missing, paste those sections. A correct version answer alone does not prove complete reference retrieval.
5. Supply the task material in the private task context. Use RESUME_GUIDE.md for continuity. A checkpoint written in chat is not automatically a saved project source.

No sharing, deployment or publication is part of setup preparation. Optional tools may stay disabled. Acceptance of the instruction field, the reference upload, tool availability and actual operation still require T3 observation. Do not truncate the active rules if an editor limit appears.

## 简体中文

1. 先确认账户／工作区提供 Projects 和可编辑的项目指令。参见 HOST_REQUIREMENTS.md；这里提供手工配置步骤，尚未在账户中执行。
2. 创建或选择目标私人项目，把 PROJECT_INSTRUCTIONS.md 的**全部内容**粘贴到项目指令设置并保存。界面名称可能不同。回读确认版本和末尾完整；仅上传为来源不能代替设置实际指令。
3. 通过可用的文件／来源入口，将 REFERENCE_PACK.md 作为一个项目来源添加，保留原文件名。UPLOAD_MAP.md 说明内容。不要把本指南、Preview 方案、设计记录、示例答案或真实检查点作为可复用知识上传。若格式或大小被拒绝，改用通用粘贴路径，不删减必需规则。
4. 在该项目内新建会话，询问实际可访问的包版本和所选流程；任务开始时要求查阅对应流程及参考。若访问不全，粘贴相应段落。答对版本号并不能证明完整检索。
5. 在私人任务上下文提供材料，并按 RESUME_GUIDE.md 续接。会话里写出检查点，不等于已另存为项目来源。

本次准备不包含共享、部署或发布。可关闭可选工具。实际指令接收、来源上传、工具能力及运行仍需 T3 观察；若编辑器出现限制，不要截断有效规则。
