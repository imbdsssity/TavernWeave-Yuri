# Continue a project / 续接项目

## English

After a completed batch, at a pause or before context handoff, retain the assistant-filled twelve-group `yuri-lite/checkpoint/v1` record. Preserve the designated ID/parent/revision, total authorization, exact segment stages/gaps, effective choices, evidence uncertainty, accepted adaptations, opening knowledge and actual draft revision. An interrupted batch needs an in-progress record.

In a new chat inside the configured project, ask it to consult the resume prompt and continuity record in REFERENCE_PACK.md. Supply your designated checkpoint, next source text, any current draft needed for exact edits and newer decisions. If project access does not expose that material, paste it. Ask for a brief restored scope/access/gaps/next-action statement, then continue available authorized work. Do not rely on history or automatic source retrieval for exact state.

When earlier evidence is missing, carried claims stay not reverified. Supply the specific contested passage when necessary. Revised/overlapping chapters require reconciliation and affected re-review; repeated checkpoints must not apply choices twice. Keep the opening's knowledge stage despite later discoveries. Save claims require observed saving: copying text, saving a file and adding a project source are separate actions.

## 简体中文

每批完成、暂停或上下文交接前，保留助手填写的十二组 `yuri-lite/checkpoint/v1`。保留指定 ID／父记录／修订、总授权、精确分段阶段与缺口、有效偏好、证据不确定性、已接受改编、开场知识边界及实际草稿版本。中断的一批应标为进行中。

在已配置项目中新建会话，让助手查阅 REFERENCE_PACK.md 中的恢复提示和连续性模板。提供指定检查点、下一批原文、精确编辑所需的当前草稿及新决定。项目不能暴露这些内容时直接粘贴。让助手简述恢复的范围、访问情况、缺口和下一步，再继续已授权且材料可用的工作。不要依靠历史或自动检索保证精确状态。

缺失的旧证据只能作为未重新核验的沿用上下文；必要时补充具体争议段落。修订／重叠章节需要核对并重审受影响部分；重复检查点不能重复应用决定。后续发现不改变原定开场知识阶段。复制文本、保存文件和添加项目来源是不同动作，只能在实际保存后声称已保存。
