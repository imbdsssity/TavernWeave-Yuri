# Compatibility and transition / 兼容与过渡

## English

See the dated official findings and exact links in HOST_REQUIREMENTS.md. The 2026-11-16 recheck confirms a transition from Custom GPTs; current official Edu guidance gives a scheduled 2026-12-11 retirement date and directs users to the owning workspace notice. This is not proof of this user's deadlines, exceptions, new-creation rights or editor availability.

Keep the compatibility package even when deployment is blocked. Use an editable legacy GPT only if the account still permits it. A read-only migrated original, stopped creation or retirement cannot be solved by uploading a ZIP. Portable and Projects remain independently prepared routes; their actual acceptance still requires observation.

For a future, separately authorized migration, retain the active instructions, full reference text, source map, notices and familiar prompts. Keep private checkpoints/current drafts separately so continuity does not depend on GPT history. Recheck reference use, capability behavior, permissions and sharing rather than assuming configuration transfers. Test relevant bounded cases before relying on a replacement. This work creates no plugin architecture and performs no migration, deployment or publication.

未来另行获授权迁移时，保留有效指令、完整参考、来源映射、声明和常用提示；私人检查点／当前草稿单独保存，避免依赖 GPT 历史。重新检查参考使用、工具行为、权限和共享，不假定配置会完整转移。依赖替代方案前执行适当的小规模检查。本次不创建插件架构，不迁移、部署或发布。
