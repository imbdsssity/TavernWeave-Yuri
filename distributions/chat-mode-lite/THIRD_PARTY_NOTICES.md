## Excluded material

No upstream CLI or 23-skill bundle, Foreverse serializer, DSH/Gemini adapter, third-party runtime, type declarations, library snapshot, fonts, artwork, real cards, novels, private casework or user checkpoints ships in these packages. The wider repository has notices for those components; their presence there does not mean they are included here. No separate vendor license is presented as a license for generated character content.

Reusable REFERENCE_PACK.md contains the sixteen canonical instruction/reference/template files, without source examples, test answer keys, design records or review receipts. Optional illustration links are pinned external traceability, not runtime requirements. The configuration's Preview plan is a human QA document and must not be uploaded as knowledge.
