# Yuri Card Workbench Lite

[English](README.md)

通过对话创作原创百合角色卡，改编已有 JSON／文本角色卡或世界书，也可以把提供的帖子、小说片段或连续章节改编成可游玩的角色与世界书草稿。连续小说使用分批处理和显式检查点衔接。

当前是**尚未发布的打包候选版本** `lite-packages/C.2`，基于 `4bdf78f9a8895d8778776e40d2efe8fb1ce6ba95`。核心及四条流程已整合；有限的代理测试发现缺陷；输出形式选择、续接验收和真实宿主验收仍未完成。Lite 不继承 Full 的二进制编辑或无损保留保证。

## 选择使用方式

| 包 | 从哪里开始 | 使用方法 |
| --- | --- | --- |
| 通用对话包 | [使用指南](packages/portable/USAGE.md) | 粘贴 START_HERE.md，再粘贴所选流程及相关参考段落和你的请求；不要求工具或附件。 |
| ChatGPT Projects | [设置指南](packages/chatgpt-projects/SETUP.md) | 将 PROJECT_INSTRUCTIONS.md 放入项目的实际指令设置，将一个 REFERENCE_PACK.md 添加为项目来源。 |
| Custom GPT 兼容包 | [配置指南](packages/custom-gpt/CONFIGURATION.md) | 仅在拥有可编辑 GPT 时使用：设置 GPT_INSTRUCTIONS.md 并上传 REFERENCE_PACK.md 为知识。先核对生命周期和账户权限。 |

每个目录都包含完整参考正文、来源映射、包清单、带核查日期的宿主说明及本地许可／声明，可单独复制使用。它们是手工设置的文本包；ZIP 不会自动安装到宿主。普通使用不需要运行脚本或安装插件。

核心指令与推理指导保留英文；你可以用中文或英文沟通，并指定草稿语言。默认采用作者定义的成年女性身份，包括虚拟及非人女性；关注主要角色，保留背景身份；仅在获授权的情境变化提供具体因果依据时调整关系结果。偏好直接在对话里说明即可。

## 开始与续接

- 原创：“创作一张原创百合角色卡。普通细节由你决定，包含可接续的开场和有正文的世界书。”
- 已有卡：提供 JSON／文本，说明实际目标版本和允许修改的范围。完整 JSON、精确字段替换和带前置检查的补丁仍是平等的待测候选，没有默认胜出形式。审阅草稿可用于讨论，不表示已应用或导入。
- 帖子：粘贴原文，说明是否包含评论和后续更新。发帖者的运行时角色始终绑定为 `{{user}}`；原文报告与虚构补充分别记录。
- 小说：给出已知的书名／版本、完整授权章节或片段范围、当前正文和开场时间限制。按需补充下一批；分批不会缩减总任务。

暂停或交接时，让助手输出当前检查点。复制完整的十二组 `yuri-lite/checkpoint/v1` 记录、必要的当前草稿及相关原文。在新会话重新启用本包，粘贴 REFERENCE_PACK.md 中的恢复提示、检查点和下一批材料，并说明新决定。项目历史只能辅助；显式确认的状态仍需保留。不要把真实检查点或私人章节加入可复用的共享 GPT 知识。

PNG 卡请提供解码后的 JSON；EPUB 请提供已提取文本。Lite 不解包或重打包这些容器。附件、联网、图像、代码、下载和保存都是可选能力；粘贴文本始终是后备路径。上传、建立索引或写出摘要不等于整章已审阅；只有整章所需工作实际完成才能如此记录。
